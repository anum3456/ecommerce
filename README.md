# PurelyOnline

PurelyOnline is a modern full-stack eCommerce application built using React, Vite, Node.js, and Express.

This project provides a clean shopping UI with fast frontend development and backend API integration.

---

# Tech Stack

* React + Vite
* Tailwind CSS
* Node.js
* Express.js
* REST API

---

# How To Run The Project

## Install All Dependencies

```bash
npm run install:all
```

---

## Start Frontend + Backend

```bash
npm run dev
```

---

# Local Development URLs

## Frontend

```bash
http://localhost:5173
```

## Backend

```bash
http://localhost:5000
```
